# Life Below Water - Website Project 🌊

This is a group coursework project for our university module. The aim is to raise awareness about marine life and ocean conservation, following the UN Sustainable Development Goal: **Life Below Water**.

## 🌐 Website Overview

The website includes:

- A Splash Screen
- Home Page
- Volunteer Information Page
- Table page
- User profile page
- Feedback Page
- Sitemap
- Team Page
- Informative Content Pages
- Page Editor
- Validation Page
