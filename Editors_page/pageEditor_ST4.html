User Profile


Technical Description


The HTML page begins with the'!DOCTYPE html' declaration to specify HTML5 document. The 'html lang="en"' tag defines the primary language of the content, which is helpful for screen readers and search engines. Inside the head section, a link to Google Fonts imports the 'Poppins' typeface, providing a clean and modern aesthetic across the page. The page also links to an external global stylesheet global.css for consistent styling throughout the website. The "meta charset="UTF-8" tag ensures proper character encoding, and the title tag gives the browser tab an appropriate title.

The page uses semantic HTML5 elements to structure content meaningfully and accessibly. A "header" contains the site logo and a horizontal navigation bar using "nav" and "a" tags, providing easy access to other parts of the site. The main body "main" is divided into multiple logical sections, each introduced by "h2" or "h3"headings for accessibility and visual hierarchy.

The profile section includes a stylized profile card featuring the user's avatar, name, and role. Adjacent to this is the profile information panel, divided into "About Me" and "Skills & Experience". Skills are visually represented using horizontal progress bars, styled through CSS width values and custom classes, which allow for dynamic presentation of expertise levels.

The volunteering activities section uses a bulleted list with relevant emojis for better visual context and engagement. The UN Sustainable Goals section displays a grid of icons and labels representing environmental goals, styled using CSS Grid for responsive layout.

The availability table utilizes the "table" element to organize volunteering times across the week in three time slots (Morning, Afternoon, Evening). Each cell uses color coding and icons to indicate availability status. Table headers and rows are semantically structured with `` and `` for clarity and screen reader compatibility.

The contact form allows users to reach out for collaboration or questions. It includes clearly labeled fields for name, email, phone number, and message. All input fields use `required` attributes for client-side validation and placeholders to guide user input. Buttons for form submission and reset are styled with distinct classes to differentiate actions visually.

The footer is divided into three key columns: About the project, Site Links, and Editors. This is followed by a horizontal rule ("hr") and a copyright statement with a W3C validation note, reinforcing commitment to accessibility standards.

From a design standpoint, the CSS emphasizes clarity and readability, aligning with the ocean conservation theme. Consistent font usage, color contrasts, spacing, and responsive layout principles are applied to ensure the page works well on both desktop and mobile devices. Icons and emojis throughout the page are used meaningfully to add visual cues and enhance user experience.

Overall, the page combines well-structured HTML and thoughtfully designed CSS to deliver an informative, accessible, and visually pleasing user profile that aligns with the mission of the Life Below Water project.


Accessibility


The User Profile page is designed with strong attention to accessibility, ensuring that users with various disabilities can navigate and interact with the content effectively.

Semantic HTML elements such as "header", "nav", "main", "section", "table", "form", and "label" are used to create a clear and meaningful structure. This improves compatibility with screen readers and other assistive technologies by helping them understand the layout and purpose of the content.

The page also includes a consistent heading hierarchy and readable fonts, enhancing clarity for all users. The use of high contrast between text and background (e.g., white text over a dark semi-transparent overlay) supports users with low vision or color blindness. Interactive elements such as buttons and links are designed with sufficient size and spacing, making them easier to click for users with motor impairments. The rating system, using emoji icons, includes title attributes (e.g., “Very Happy”), providing descriptive tooltips for screen reader users or those who may not understand the symbols. Moreover, the site follows W3C standards and includes a footer note stating adherence to accessibility guidelines, showing a commitment to inclusivity. Alt attributes on images such as the logo also ensure that non-visual users receive context for graphical content. Altogether, these features contribute to a well-structured, accessible web page that aligns with best practices in inclusive web design.


Form fields are correctly associated with their "label" tags through the for and id attributes, making each input easily identifiable for screen reader users. Required fields are visually marked with a red asterisk and include the required attribute, ensuring both visual and non-visual users know which fields must be completed.

A proper heading hierarchy ("h1", "h2", "h3") is maintained, allowing users who rely on screen readers or keyboard navigation to quickly scan and understand the page structure. The font used throughout is "Poppins", which provides modern and high readability.

There is a high contrast between text and background—white text over a dark semi-transparent overlay—making the content accessible to users with low vision or color blindness.

All interactive elements, such as links and buttons, have sufficient size and spacing for users with motor impairments to interact with them easily. Emoji icons used for feedback and goals include "titl" attributes that provide descriptive tooltips for screen readers and users unfamiliar with emoji meanings (e.g., title="Very Happy").

All images, such as the site logo, include `alt` attributes to ensure that non-visual users receive a meaningful description of graphical elements. Additionally, the page includes a footer note that confirms adherence to accessibility guidelines and W3C web standards, reflecting a commitment to inclusive design.

Together, these accessibility features — including responsive layout, clear labeling, semantic structure, descriptive tooltips, and proper contrast — contribute to a user-friendly and inclusive experience that aligns with best practices in accessible web development.

Site Map


Technical Description


The Page Editor section within the Site Map is designed to visually represent the editing and contribution roles of each student developer in the Ocean Conservation Initiative website. It uses nested HTML anchor ("a") tags styled with custom CSS classes such as "node" and "sub-node" to differentiate between the main editor page and individual student contribution pages. The layout employs a hierarchical structure, grouping editor links under the Page Editor node, with child nodes branching out to represent each students specific focus area, such as Marine Biology and Pollution Analysis. This logical grouping enhances navigation clarity. The connections between nodes are visually represented using styled "div" elements ("connection", "sub-nodes") to simulate a flowchart-like structure. The entire section is enclosed within a container (".level-container") to maintain structural consistency and responsive alignment. These HTML and CSS design strategies ensure the section is both functional and accessible across different screen sizes and input methods.


Accessibility


Accessibility was thoughtfully integrated into the Site Map Page to ensure that all users, including those with disabilities, can navigate and interact with the content effectively.

Semantic HTML elements such as <header>, <nav>, <footer>, and descriptive headings like <h1> were used to establish a clear and logical page structure. This helps screen readers interpret the content hierarchy, enabling visually impaired users to understand the overall structure of the site through assistive technologies.

All navigation links within the page, including the interactive site map nodes, use meaningful link text (e.g., “🏠 Home”, “✏️ Page Editor”) to ensure that users know where each link leads, without relying on visual cues. These links are implemented using <a> tags and are naturally keyboard-navigable, supporting tab-based navigation for users who do not use a mouse.

The visual layout of the map includes logical grouping and spacing of elements, helping cognitive and neurodiverse users follow the site flow. Dividers and connections are visual enhancements only, and they do not interfere with screen reader usability. Where needed, alt attributes are provided for images like the site logo, making non-text content accessible through descriptive alternative text.

The page uses high-contrast colors (e.g., dark text on light backgrounds), readable fonts (Poppins), and appropriate font sizes to enhance readability for users with low vision or dyslexia. Responsive design ensures that the layout remains accessible on different devices and screen sizes, including mobile and tablet.

Finally, a footer note confirms the website’s adherence to accessibility guidelines and W3C validation standards. Together, these design decisions demonstrate a commitment to inclusive and universal access, covering principles such as semantic markup, keyboard accessibility, text alternatives, visual clarity, and responsive behavior.

Content Page


Technical Description


It uses semanti

This content page on "Marine Pollution-Protecting Our Oceans" is structured using semantic HTML5 elements to ensure both clarity and accessibility. The layout is divided into a responsive two-column design, featuring a vertical side navigation (nav class="nav1") and a main content area (div class="content-wrapper"). The side navigation provides quick anchor links to key sections of the page, improving user navigation and enhancing UX for long-form content.

Each thematic section (e.g., Causes, Impacts, Statistics, Solutions) is implemented using "section" tags with unique "id" attributes, enabling smooth in-page linking and scroll behavior. Headings from "h1" to "h4" are used hierarchically to organize content, making it screen-reader friendly and search-engine optimized.

Visual content is managed through "img" elements placed within styled containers (".image-container"). Each image includes a descriptive "alt" attribute and caption to support accessibility. Lists ("ul", "ol") and styled statistic boxes (".stats-grid") are used to present data in a digestible and visually appealing way.

The page integrates external CSS stylesheets ("global.css", "contentpage_ST4.css") and Google Fonts (Poppins) for consistent visual styling and readability. It uses a responsive design layout, ensuring usability across desktops, tablets, and mobile devices. A "Go to Top" button is implemented via JavaScript to improve page navigation and user convenience.

At the bottom, a "footer" section provides consistent site-wide information and navigation links, enhancing usability and site coherence. The entire page adheres to W3C standards and accessibility guidelines, supporting inclusive access for all users.


Accessibility


Accessibility has been carefully considered throughout the design and implementation of this content page to ensure inclusive access for users of all abilities. The page uses semantic HTML elements like "header", "nav", "main", "section", and "footer" to create a logical content structure, improving screen reader interpretation and overall navigability.

All images include descriptive `alt` attributes (e.g., "Sea turtle entangled in plastic debris"), allowing users with visual impairments to understand visual content through screen readers. Image captions further enhance comprehension for all users, including those with cognitive impairments.

The side navigation menu is implemented using a "nav" element and anchor links with clear labels that enable keyboard users to quickly skip to different sections using the Tab key or screen reader shortcuts. All links and buttons, including the "Go to Top" button, are fully keyboard-navigable.

Text contrast between foreground and background colors meets WCAG contrast guidelines, improving readability for users with visual impairments or color blindness. The use of the "Poppins" font with sufficient font size and spacing ensures comfortable reading across devices and screen resolutions.

Content is divided into logically grouped sections using appropriate heading levels (`"h1" to "h4"), making it easier for screen readers to announce and navigate through the document structure. Lists and data are presented in accessible formats using semantic "ul", "ol", and "li" elements to support assistive technologies.

Finally, the page is responsive and maintains usability across different screen sizes and input types, including touch, mouse, and keyboard navigation. The footer includes a statement confirming that the website follows accessibility guidelines and W3C validation, ensuring compatibility with modern assistive tools and inclusive web standards.

Challenges and Lessons Learned


Organizing long content was tricky. It was difficult to keep the page user-friendly without proper structure, so sections and anchor links were used.

Making the layout responsive took effort. The content didn’t display well on small screens at first and needed media queries and layout adjustments.

Ensuring image accessibility was challenging. Each image needed meaningful alt text to support screen reader users.
