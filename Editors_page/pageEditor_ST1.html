Splash screen


Technical Description


This code creates a visually appealing splash screen for a website with the theme “Life Below Water”. The splash screen auto-redirects to the homepage after 4 seconds using: <meta http-equiv="refresh" content="4; url=../home_page/homepage.html">


The key components of this webpage include a structured HTML layout and CSS-based design. The <div class="ripple-shower"> creates animated ripple effects at the top center of the screen, while <header class="header"> displays social media icons aligned to the right. The main visual area is structured within <div class="banner">, which features a full-screen background and two sections: .left-info showing the title "AQUA" along with a list of group members, and .right-info presenting "VERSE" and a slogan. The CSS styling uses the Poppins font, ensures full responsiveness with width: 100% and height: 100vh, and applies a translucent blur effect (backdrop-filter: blur(20px)) through the .penetrate-blur class to improve text readability. Ripple animations are defined using @keyframes to simulate water-like motion by scaling and fading circles, and the icons are loaded via the Boxicons CDN. Additionally, three ripple circles animate sequentially using the .ripple, .delay1, and .delay2 classes to create a dynamic visual effect.


Accessibility


While visually appealing, the current splash screen lacks several critical accessibility features. It does have some strengths, such as semantic HTML usage with elements like <header>, <ul>, <h1>, and <h2>, which help screen readers understand the structure, and the image uses alt text (<img src="Images/background.jpg" alt="Under water picture.">), aiding visually impaired users. Additionally, social media icons are wrapped in <a> tags, making them accessible via keyboard and screen readers. However, several accessibility issues remain: the white text and icons over bright background areas may have poor color contrast, which can be problematic for users with low vision. Focus indicators are missing, so keyboard users may not see where they are navigating. There's no "skip to content" link to help users bypass decorative elements. Decorative elements like .ripple-shower lack aria-hidden="true", which can confuse screen readers. Animations might cause discomfort for users with motion sensitivity; this can be addressed using the @media (prefers-reduced-motion: reduce) query to disable such effects. Lastly, the automatic redirect after 4 seconds could be frustrating for slow readers or screen reader users. It's best to include a manual link such as “Click here if you are not redirected automatically”.

Volunteer Page


Technical Description


This volunteer page is a well-structured, responsive HTML document styled primarily with CSS, using the Poppins font for modern typography. It features a fixed header with a logo and clear navigation links, followed by a hero section encouraging users to join marine conservation efforts. The page includes a sortable volunteer programs section displayed in a grid layout with cards showcasing different initiatives, each containing images, descriptions, and call-to-action buttons. User reviews are presented in a responsive card layout, and a feedback form with accessible input fields allows users to submit comments. The design incorporates smooth hover effects, consistent spacing, and adaptive layouts to ensure usability across devices from desktops to mobile. Gradients and shadows add visual depth, while media queries adjust the layout for smaller screens, ensuring a user-friendly experience.


Accessibility


This page employs semantic HTML elements and provides descriptive alt text for all images, aiding screen reader users in understanding content and visuals. The navigation is keyboard-accessible with clear focusable links, and form fields include placeholders to guide users in submitting feedback. Responsive design ensures content readability on various screen sizes, and color contrasts have been chosen to meet accessibility standards for sufficient visibility. Buttons and interactive elements have clear visual feedback on hover and focus states, supporting users with different interaction methods. While animations are minimal to avoid motion discomfort, the page structure facilitates easy navigation and comprehension, making it inclusive for users with disabilities.

Content Page


Technical Description


This content page is built with semantic HTML and styled using custom CSS to present educational information about endangered marine species. It features a responsive two-column layout, with a sticky vertical navigation menu on the left for quick access to various sections such as Introduction, Threatened Species, Causes, Conservation, and Conclusion. Each section is wrapped in styled containers with headings, informative text, and centered images that scale responsively. The design utilizes the Poppins font for clarity and aesthetics, consistent padding and shadows for visual structure, and a prominent “Back to Top” button for improved navigation. The footer includes contact details, navigation links, and editor credits, offering a complete and cohesive user experience across screen sizes via media queries.


Accessibility


This page supports accessibility by using structured headings (<h1>, <h2>, <h3>) for content hierarchy and navigation, descriptive alt text for all images to aid screen reader users, and clearly styled links with hover effects for visual feedback. The sticky side navigation provides efficient keyboard and screen reader access to key sections without scrolling. The font size and color contrast between text and background have been chosen for readability, while responsive adjustments ensure that content remains accessible on smaller screens. Additionally, the fixed "Top" button improves user mobility across long content sections, making the page more inclusive for users with mobility or visual challenges.

Challenges and Lessons Learned


During the development of the splash screen, volunteer page, and content page, I encountered several challenges that helped me grow as a developer. The splash screen's ripple animation needed to be carefully timed to not conflict with the redirect, and positioning it visually at the top center while keeping the animation smooth was tricky. On the volunteer page, balancing layout responsiveness and clean card alignment for different screen sizes required multiple adjustments. The content page, which had long-form educational material and internal navigation, demanded attention to readability and section flow. Through these experiences, I learned the importance of consistent class usage, mobile-first design, and organizing HTML for better collaboration and reusability.


Compliance


I ensured that the pages I created complied with key web development standards. All HTML was validated against W3C guidelines, and semantic elements like <section>, <nav>, and <header> were used for better accessibility. All images included descriptive alt text, and font and color combinations were selected to ensure sufficient contrast. Interactive components like buttons and links were styled with clear hover effects for usability. External resources like Google Fonts and Boxicons were properly linked via CDNs, ensuring reliability and speed. Throughout development, I followed best practices for structure, responsiveness, and code clarity.


References


The resources I used while creating my pages included trusted documentation platforms like W3Schools and MDN Web Docs for HTML and CSS references. For design inspiration and layout ideas, I referred to various conservation-themed websites. YouTube tutorials were helpful for implementing ripple effects and responsive card designs. All fonts were sourced from Google Fonts, and iconography was implemented using Boxicons via CDN. The images used were either group-created, royalty-free, or credited accordingly, and were optimized with alt text for accessibility. These references supported the design and technical accuracy of the pages.
