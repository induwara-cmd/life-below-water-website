Home Page


Technical Description


The homepage is built using semantic HTML structure and CSS styling to create a clean, user-friendly layout focused on marine conservation under the theme "Life Below Water." The main content begins with a bold heading inside the main content wrapper, placed strategically below the fixed navigation using margin spacing. This heading is styled with a large font size and themed color to instantly convey the site’s purpose. All major content is grouped inside a central container with flexible sizing to ensure consistency across various screen sizes.The "About Us" section is one of the key content blocks, built using a combination of layout containers like "section" and "div" elements. The layout is handled using Flexbox, which allows the text content and the image to be placed side by side on larger screens. This visual arrangement creates balance and improves readability. The text block is styled with a soft background color, rounded corners, a solid border, and subtle shadowing, giving it a modern card-like appearance. The heading within this block is center-aligned and visually emphasized using an underline created through a pseudo-element. The paragraph text is carefully spaced and justified, improving overall legibility and aesthetics.The "Our Mission" section follows a similar card-based visual design but stands out with its light blue background that spans the full width of the container. Inside this area, the mission content is placed within a centered box that uses padding, shadows, and rounded borders to separate it from the background. Text within the mission box is centered and broken into short, digestible paragraphs. These layout and styling choices help the user focus on the key goals and objectives of the project without feeling overwhelmed.One of the most visually engaging components is the "Contents" section. It features a grid of four content cards, each representing a core topic related to marine conservation. These cards are built using CSS Grid layout, with equal column spacing and gap values that maintain a clean look. Each card includes an image, a heading, a brief description, and a “Read More” link styled to resemble a small button. Visual depth is added using drop shadows, and interactivity is introduced through hover effects, where each card lifts slightly and changes shadow intensity to create a responsive feel. The link uses rounded corners and background color transitions to stand out as a clickable element without overwhelming the design.To maintain responsiveness, the design uses media queries that adapt the layout based on screen width. For example, the grid layout in the contents section shifts from four columns to two and then to one as the screen gets smaller. Similarly, the "About Us" Flexbox layout switches to a vertical stack on mobile devices to keep content accessible. Padding and spacing values are also adjusted to prevent overflow and maintain visual hierarchy on all screen sizes.Overall, the homepage design effectively combines structured HTML and modern CSS to deliver a well-balanced, informative, and visually appealing experience. The use of Flexbox and Grid enables precise control over layout, while shadows, colors, and transitions enhance user interaction and align with the oceanic theme. Every element is intentionally placed and styled to guide the visitor smoothly through the purpose and values of the site.


Accessibility


Accessibility has been considered in the homepage design to ensure the content is usable for a wide range of users, including those with disabilities. Semantic elements such as "header", "main", "section", and "footer" are used to provide clear content structure, which helps screen readers and assistive technologies interpret the page accurately. Descriptive "alt" text is provided for all images, including the project logo and content visuals, allowing visually impaired users to understand the visual context through screen readers. The color scheme maintains sufficient contrast between text and background, ensuring readability for users with low vision or color blindness. Interactive elements such as the navigation links and “Read More” buttons are designed to be clearly distinguishable and include visual feedback on hover to support keyboard navigation and focus indication. Additionally, headings follow a logical order and content is organized with appropriate spacing, which enhances overall readability and user experience for all visitors.

Table Page


Technical Description


The marine cleanup comparison table page is developed using semantic HTML and structured CSS to present data in an accessible, organized, and visually engaging format. The core of the page is built around the "table" element, which is enhanced through a combination of "thead", "tbody", and "tr" structures to separate the header and body content logically. This semantic structure supports screen readers and improves clarity for users viewing tabular data. Each header cell ("th") is used to label its corresponding column, ensuring that users can easily scan and understand the dataset. A custom "section-header" class is applied to the top row of headers to visually highlight the start of the data section with bold typography and a deeper background color. CSS Grid or Flexbox was not used for layout here, as the tabular structure is naturally suitable for presenting comparative data. Instead, styling is applied directly to the table using properties like border-collapse, width, box-shadow, and border-radius to achieve a clean, modern card-like appearance. The alternate row coloring (nth-child(even)) helps visually separate data entries for readability. Interactive feedback is also added via a hover effect on rows (:hover), giving users subtle visual cues as they explore the table. Iconography is handled using Font Awesome icons placed inside the "td" cells, conveying the status of each program—such as verified or not verified—using familiar symbols like ticks and crosses. These icons include "aria-label" and "title" attributes to enhance accessibility for screen readers and users relying on tooltips. The "button" elements in the last column allow interaction by letting users select a program. These buttons are styled with consistent padding, background color, font settings, and hover effects using transitions to ensure a polished user experience.The overall layout is centered on the page using margin auto and max-width constraints on the "pricing-table" container, while internal spacing is controlled through padding. A custom ribbon section at the top is used to introduce the table category with badge styling for emphasis. Additionally, responsive design is handled using a media query for screen widths below 768px, adjusting font sizes, paddings, and button dimensions to maintain usability on mobile and tablet devices.In summary, this table page demonstrates a strong balance of structured HTML and visually effective CSS. It successfully presents complex comparative data in a user-friendly and accessible format, supporting both functional clarity and consistent visual identity within the wider website.


Accessibility


Accessibility was a key consideration in the implementation of the table page to ensure that all users, including those with disabilities, can access and understand the content effectively. The page uses semantic HTML elements such as "table", "thead", "tbody", and "th" to create a structured, screen reader-friendly layout. An "aria-label" is applied to the main table to clearly describe its purpose to assistive technologies. Font Awesome icons used for verification status include "aria-label" and "title" attributes, which provide descriptive tooltips and audio cues for screen reader users. Button elements are designed with clear labels and a visible focus state to support keyboard navigation. The color scheme ensures adequate contrast between text and background, meeting WCAG standards for visual clarity. Hover and focus effects on rows and buttons improve the interactive experience without relying solely on color cues, making it accessible to users with color blindness. Responsive design also contributes to accessibility by maintaining readable layouts across different devices and screen sizes. These combined efforts make the table both informative and inclusive.

Content Page


Technical Description


The Coral Reefs and Ecosystems content page was built using a structured and responsive HTML layout enhanced by purposeful CSS styling to improve readability, navigation, and user experience. The page layout is divided into a two-column structure using a flex container, where the left column serves as a vertical side navigation menu and the right column presents the main content. The side menu uses a combination of "position: sticky" and a fixed "top" value to keep it visible while scrolling, ensuring easy access to internal links throughout the page. Each menu item links to specific sections via anchor IDs, providing intuitive in-page navigation. The main content uses multiple reusable containers styled as cards to organize different thematic sections such as introduction, importance, threats, and conservation. These sections are wrapped in styled content blocks with consistent padding, border-radius, and box shadows to create visual depth and separation. Typography is controlled through properties like "font-size", "line-height", and "color" to enhance readability and create hierarchy between headings and paragraph content. Background colors like white and soft blues are chosen to reflect the ocean theme while maintaining contrast and clarity. Images are integrated within each section using responsive styles to ensure they scale proportionally on different screen sizes. Each image is center-aligned with borders and rounded corners to maintain a modern, cohesive visual appearance. The layout uses media queries to adapt on smaller devices, ensuring the content remains accessible and well-formatted across screen sizes. The fixed "Go to Top" button improves user navigation and is styled with shadows and hover transitions for interactivity. Overall, this design leverages semantic HTML structure for clarity and maintainability while CSS is used not only for aesthetics but also to enhance usability, structure, and content flow.


Accessibility


Accessibility has been thoughtfully integrated into this page to ensure that it is usable and inclusive for a diverse range of users, including those relying on assistive technologies. The layout uses clear section headings and descriptive link labels to enhance navigability for screen readers. Anchor-based in-page navigation allows users to skip directly to relevant content, reducing the need for excessive scrolling — particularly helpful for users with mobility impairments. Alt text is provided for all images to describe their content for users who are visually impaired, ensuring that essential visual information is conveyed even without sight. The chosen font, color contrast, and generous line spacing contribute to visual clarity, which benefits users with low vision or reading difficulties. Color choices were carefully made to meet WCAG contrast guidelines, especially between text and background colors, improving overall legibility.Interactive elements like the “Go to Top” button are designed with keyboard accessibility in mind and are styled clearly with hover effects for better visibility. The side navigation remains visible as users scroll, helping those with cognitive disabilities maintain orientation on the page. Moreover, the structure of the HTML ensures a logical reading order, which is crucial for assistive technologies to interpret the content correctly. Altogether, these features promote a more accessible, user-friendly experience for all visitors, reinforcing the site’s commitment to inclusive design.

Challenges and Lessons Learned


During the development of the PlanetBlue website’s home page, table page, and content page, several technical and design challenges emerged that required careful problem-solving and adaptation. One significant challenge was ensuring consistent responsive layouts across different screen sizes and devices. Each page had unique layout demands—the home page with its content-rich card grid, the table page displaying detailed multi-column data, and the content page featuring a sticky side navigation alongside multi-section content. Early on, the use of fixed widths and padding sometimes caused overlapping or awkward content wrapping. This was resolved by employing CSS grid and flexbox techniques more effectively, using relative units instead of fixed pixel values, and adding media queries to make the layouts fluid and adaptable, thus maintaining readability and usability on desktops, tablets, and mobiles. Another challenge was integrating accessibility features while incorporating visual elements like icons and interactive buttons. Initially, some icons lacked descriptive alternative text or ARIA labels, which could confuse screen reader users. Addressing this involved adding appropriate aria-label attributes and descriptive texts to icons and buttons, improving the inclusivity and navigability of the website for users with disabilities. Implementing the sticky side navigation on the content page also proved challenging due to conflicts between the position: sticky CSS property and other global or parent container styles. Through testing and isolating conflicting CSS rules, this behavior was fine-tuned to ensure the side navigation remained fixed in view without disrupting the overall layout or causing unwanted spacing issues. The table page required balancing semantic HTML structure with modern visual styling, such as rounded corners, shadows, and hover effects. It was important to maintain correct use of HTML table elements to preserve accessibility and readability while applying CSS properties like border-collapse and box-shadow for a polished appearance. Furthermore, managing relative file paths for navigation links and resources across multiple nested folders was complex. Careful folder organization and consistent path referencing ensured that links and assets loaded correctly across all pages. These challenges collectively reinforced key lessons in web development. Planning flexible and responsive CSS layouts early in the design process proved essential for cross-device compatibility. Maintaining semantic and accessible HTML structure ensured that the website remained usable for all visitors, including those relying on assistive technologies. Regular testing across browsers and devices helped catch layout inconsistencies and bugs. Finally, a well-organized project structure facilitated easier asset management and navigation linking. Through overcoming these obstacles, the final website achieved a user-friendly, visually appealing, and accessible experience that aligns with modern web standards and best practices.


Compliance


The web pages developed for this project have been created with careful consideration of Janet regulations governing web page publication, particularly focusing on accessibility, privacy, and security standards. Janet requires that public-facing websites be accessible to all users, including those with disabilities, which aligns closely with the Web Content Accessibility Guidelines (WCAG). To meet these requirements, semantic HTML tags have been used throughout the pages to ensure clear document structure, and ARIA attributes have been applied where necessary—especially in navigation menus, tables, and interactive elements—to support screen readers and other assistive technologies. Alt attributes are provided for all meaningful images, ensuring that visual content is accessible to users who rely on text descriptions. In terms of privacy and security compliance, the pages do not collect or store any personal user data directly. However, the navigation links and content reflect a structure that would allow secure handling of user interactions, such as login or feedback pages, which would be implemented with appropriate data protection measures in a full deployment. Additionally, external resources like Google Fonts and Font Awesome icons are loaded via HTTPS to ensure secure content delivery. The site avoids any use of outdated or insecure technologies and maintains a clean, standards-compliant codebase that aligns with Janet’s expectations for reliable and maintainable web content. Furthermore, the design is tested across multiple browsers and devices to maintain consistent functionality and user experience, which is critical for compliance with Janet’s guidance on quality and usability. By following these principles, the website meets Janet’s fundamental requirements for accessibility, security, and professionalism in web publication, making it fit for educational and institutional use within the Janet network environment. Any limitations, such as the lack of user data handling or advanced security measures, are acknowledged as beyond the current scope but would be addressed in a live production setting to maintain full compliance.
