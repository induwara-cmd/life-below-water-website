2. Technical Description

Feedback Form

I used a visually engaging background image with an overlay to improve readability. The form uses semantic tags like <form>, <fieldset>, and <label> for structure. Required fields and pattern validation ensure data accuracy. CSS was used for styling with shadows, hover transitions, and responsive layouts. For accessibility, proper label tags are linked with form controls.

Team Page

The Team Page was built using <div> containers with flexbox to create a responsive layout. I implemented hover effects with CSS transitions to scale individual cards for interactivity. I used :hover and :focus to enhance accessibility. Cards are styled with box shadows and smooth border-radius effects.

Content Page – Sustainable Fishing

This page uses a flex layout to place the sidebar and main content. The <section> tags structure each topic area, supporting accessibility and readability. Key CSS features include color-coded containers, sticky navigation, and a back-to-top button. I used consistent font sizing, spacing, and shadowing for a modern look. Images are responsive and styled with borders and spacing.

3. Challenges and Lessons Learned

One challenge was getting the flexbox layout to behave consistently across screen sizes. I resolved this by applying responsive media queries. I also initially struggled with form validation but overcame this by reviewing HTML5 validation attributes. This project helped me better understand accessibility and responsive design.

4. Accessibility

All pages use semantic HTML, including headings and ARIA-friendly structures. Form fields use label elements correctly. The site has good contrast, readable fonts, and interactive elements like buttons have hover/focus states. The content is screen-reader friendly and the navigation is keyboard-accessible.

5. Compliance

My pages adhere to Janet Web Publishing Guidelines. They avoid offensive content, are educational in purpose, and protect user data. I have not included any tracking cookies or third-party scripts. Forms use HTML5 validation for safer input handling. Media is attributed or royalty-free.
